**Neon Harbor** — an original open-world crime game in the sunset port city of Port Vela. Play as Maya Reyes, a courier with empty pockets and a fixer who never forgets a debt: steal cars, outrun the Port Vela police, and run four jobs for Otto "Ledger" Kline before Rook and the Breakers run you out of town. Explore the city on foot and by car, with AI traffic, fleeing pedestrians, a 1–5 star wanted system, pistol and fist combat, a live minimap, and a localStorage save. Fully offline — three.js is vendored, all sound is synthesized with WebAudio, and there are no network requests.

Jobs: Hot Wheels ($400) — steal the yellow sedan at the docks and deliver it to Otto's garage. Harbour Lights ($600) — pick up a package at the marina pier and drop it at the lighthouse. Heat Wave ($800) — raise two wanted stars, then lose them all. Midnight Run ($1,500) — five checkpoints across Port Vela in 90 seconds.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
